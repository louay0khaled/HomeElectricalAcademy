# محرك محاكاة الدوائر الكهربائية المنزلية المتقدم

## نظرة عامة
تم تطوير محرك محاكاة متقدم يحاكي بدقة المنظومة الكهربائية المنزلية الكاملة من عمود الكهرباء الحكومي وصولاً إلى كل مقبس ولمبة في المنزل. هذا المحرك هو القلب النابض للتطبيق التعليمي التفاعلي.

## المكونات الرئيسية

### 1. ElectricalComponent (المكونات الكهربائية)
نموذج شامل يمثل جميع المكونات الكهربائية المستخدمة في التمديدات المنزلية:

#### أنواع المكونات:
- **PowerSource**: مصدر الطاقة (شبكة الكهرباء الحكومية - 220V/50Hz)
- **Load**: الأحمال الكهربائية (إضاءة، أجهزة منزلية)
- **CircuitBreaker**: قواطع الحماية بأنواعها (MCB, MCCB, RCCB, RCBO)
- **Wire**: الأسلاك الكهربائية بمقاطع مختلفة (1.5mm² إلى 25mm²)
- **Ground**: أنظمة التأريض (قضيب، صفيحة، شبكة)
- **Socket**: المقابس الكهربائية (شوكو، أمريكي، بريطاني، صناعي)
- **Switch**: المفاتيح الكهربائية (أحادي، ثنائي، ثلاثي المسار، مخفت)

#### الخصائص المحسوبة:
- المقاومة الكهربائية (أوم)
- أقصى تيار مسموح (أمبير)
- القدرة الاسمية (وات)

### 2. HomeCircuit (الدائرة المنزلية)
نموذج يمثل دائرة كهربائية كاملة مع:
- حساب المقاومة الكلية
- حساب التيار باستخدام قانون أوم (I = V/R)
- حساب القدرة المستهلكة (P = V × I)
- كشف قصر الدائرة
- كشف الحمل الزائد
- محاكاة فصل القواطع
- التحقق من سلامة التأريض

### 3. DistributionBoard (لوحة التوزيع)
نموذج لوحة التوزيع الرئيسية:
- القاطع الرئيسي (50-63 أمبير)
- قاطع التسرب الأرضي (RCCB)
- نظام التأريض
- قواطع الدوائر الفرعية
- واقي زيادة الجهد (اختياري)

#### الوظائف:
- حساب الحمل الكلي على اللوحة
- التحقق من السعة الآمنة
- محاكاة الأعطال الشاملة
- إدارة الدوائر الفرعية

### 4. CircuitSimulationEngine (محرك المحاكاة)
المحرك الرئيسي الذي يدير عمليات المحاكاة:

#### الوظائف الأساسية:
1. **setupHomeElectricalSystem()**: إعداد النظام الكهربائي الكامل من العمود الحكومي
2. **addCircuitToBoard()**: إضافة دوائر جديدة للوحة التوزيع
3. **analyzeCircuit()**: تحليل دقيق للدائرة باستخدام قوانين كيرشوف
4. **simulateLoadOperation()**: محاكاة تشغيل/إيقاف الأحمال
5. **simulateFault()**: محاكاة الأعطال المختلفة
6. **analyzeCompleteSystem()**: تحليل شامل للمنظومة الكاملة

#### التحليلات المقدمة:
- المقاومة الكلية والتيار والقدرة
- هبوط الجهد في الأسلاك
- كفاءة الدائرة
- حالة الدائرة (نشطة، قصر، حمل زائد، إلخ)
- درجة السلامة (0-100)
- تقرير الأعطال المفصل

## أنواع الدوائر المنزلية المدعومة

| النوع | القاطع النموذجي | نوع السلك | الاستخدام |
|-------|----------------|-----------|-----------|
| إضاءة | 10 أمبير | نحاس 1.5mm² | الإنارة الداخلية والخارجية |
| مقابس عامة | 16 أمبير | نحاس 2.5mm² | المقابس العادية |
| مطبخ | 20 أمبير | نحاس 4mm² | أجهزة المطبخ عالية الاستهلاك |
| مكيف هواء | 20 أمبير | نحاس 4mm² | وحدات التكييف |
| سخان مياه | 25 أمبير | نحاس 6mm² | السخانات الكهربائية |
| غسالة | 16 أمبير | نحاس 2.5mm² | الغسالات والمجففات |
| رئيسية | 63 أمبير | ألومنيوم 25mm² | التغذية الرئيسية |

## أنواع الأعطال المدعومة

1. **قصر الدائرة (SHORT_CIRCUIT)**: مقاومة منخفضة جدًا تسبب تيار عالي خطير
2. **الحمل الزائد (OVERLOAD)**: تيار يتجاوز سعة القاطع
3. **قاطع مفصول (BREAKER_TRIPPED)**: قاطع فصل بسبب عطل
4. **تأريض ضعيف (POOR_GROUNDING)**: مقاومة تأريض عالية (>10 أوم)
5. **دائرة مفتوحة (OPEN_CIRCUIT)**: انقطاع في المسار
6. **هبوط جهد (VOLTAGE_DROP)**: فقدان جهد في الأسلاك الطويلة
7. **جهد عالي (OVERVOLTAGE)**: زيادة الجهد عن الحد المسموح
8. **تيار تسرب (LEAKAGE_CURRENT)**: تسرب تيار للأرض
9. **اتصال رخو (LOOSE_CONNECTION)**: توصيل غير محكم يسبب سخونة
10. **عزل تالف (DAMAGED_INSULATION)**: تلف عزل الأسلاك

## درجات شدة الأعطال

| الشدة | اللون | الوصف | الإجراء المطلوب |
|-------|-------|-------|-----------------|
| لا يوجد | أخضر | النظام سليم | لا شيء |
| منخفض | أصفر فاتح | أعطال بسيطة | مراقبة |
| متوسط | برتقالي | مشاكل متوسطة | صيانة قريبة |
| عالي | أحمر | أخطار محتملة | تدخل عاجل |
| حرج | أحمر داكن | خطر فوري | إيقاف فوري وإصلاح |

## السيناريوهات التطبيقية

### سيناريو 1: تمديد غرفة معيشة كاملة
```kotlin
val engine = CircuitSimulationEngine()
val system = engine.setupHomeElectricalSystem()

// إضافة دائرة الإضاءة
val lights = listOf(
    Load("light_main", "إضاءة رئيسية", LoadType.LIGHT, 100.0),
    Load("light_accent", "إضاءة زينة", LoadType.LIGHT, 40.0)
)
engine.addCircuitToBoard(CircuitType.LIGHTING, "إضاءة الصالة", lights)

// إضافة دائرة المقابس
val appliances = listOf(
    Load("tv", "تلفاز", LoadType.TV, 150.0),
    Load("ac", "مكيف", LoadType.AIR_CONDITIONER, 1500.0)
)
engine.addCircuitToBoard(CircuitType.SOCKETS, "مقابس الصالة", appliances)

// تحليل النظام
val analysis = engine.analyzeCompleteSystem()
println("درجة السلامة: ${analysis.getSafetyRating()}")
```

### سيناريو 2: محاكاة حمل زائد في المطبخ
```kotlin
val kitchenAppliances = listOf(
    Load("microwave", "ميكروويف", LoadType.MICROWAVE, 1000.0),
    Load("kettle", "غلاية", LoadType.KETTLE, 1500.0),
    Load("toaster", "محمصة", LoadType.TOASTER, 800.0)
)

val circuit = engine.addCircuitToBoard(
    CircuitType.KITCHEN, 
    "دائرة المطبخ", 
    kitchenAppliances
)

// تشغيل جميع الأجهزة معًا
kitchenAppliances.forEach { appliance ->
    val result = engine.simulateLoadOperation(circuit, appliance.id, turnOn = true)
    if (result.trippedBreakers.isNotEmpty()) {
        println("⚠️ تنبيه: ${result.message}")
    }
}
```

### سيناريو 3: كشف الأعطال وتشخيصها
```kotlin
val circuit = engine.addCircuitToBoard(
    CircuitType.SOCKETS,
    "دائرة الاختبار"
)

// محاكاة قصر دائرة
val faultResult = engine.simulateFault(circuit, FaultType.SHORT_CIRCUIT)

if (faultResult.faultReport?.hasCriticalFaults == true) {
    println("🚨 عطل حرج: ${faultResult.faultReport.getSummary()}")
    println("الإجراء: افصل الطاقة فورًا!")
}
```

## المعادلات الحسابية المستخدمة

### قانون أوم
```
V = I × R
I = V / R
R = V / I
```

### حساب القدرة
```
P = V × I
P = I² × R
P = V² / R
```

### مقاومة السلك
```
R = ρ × (L / A)
حيث:
ρ = المقاومية النوعية للنحاس (0.0171 أوم·مم²/م)
L = طول السلك (متر)
A = مقطع السلك (مم²)
```

### هبوط الجهد
```
ΔV = I × R_wire
نسبة الهبوط = (ΔV / V_source) × 100%
```

### كفاءة الدائرة
```
الكفاءة = (مقاومة الحمل / المقاومة الكلية) × 100%
```

### درجة السلامة
```
الدرجة = 100 - (عدد الأعطال × 10) - (خصومات إضافية)
الخصومات الإضافية:
- عطل حرج: -30
- تأريض سيء: -20 إلى -25
- حمل زائد: -15
```
