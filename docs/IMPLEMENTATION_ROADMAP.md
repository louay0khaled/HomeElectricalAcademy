# Implementation Roadmap

## Milestone 1 — Foundation

- Android project skeleton
- Kotlin + Compose architecture
- Design system
- Navigation shell
- Dependency injection
- Local persistence
- Domain/content model
- CI build and test pipeline

## Milestone 2 — Scientific Learning Core

- Lesson renderer
- Equations and diagrams
- Interactive variables
- Concept checks
- Progress tracking
- First circuit simulation

## Milestone 3 — Virtual Electrical Lab

- Component palette
- Wiring canvas
- Source/load/switch components
- Live electrical state
- Multimeter interaction
- Prediction vs measurement exercises

## Milestone 4 — Residential Systems

- Distribution-board model
- Circuit groups
- Lighting circuits
- Socket/receptacle circuits
- Dedicated loads
- Protective-device models
- Configurable standards profiles

## Milestone 5 — House Blueprint

- Room editor
- Electrical-point placement
- Routes
- Circuit assignment
- Layer visibility
- Circuit tracing
- Project save/resume

## Milestone 6 — Troubleshooting Lab

- Fault injection framework
- Measurement-driven diagnosis
- Hint system
- Scoring
- Randomized fault scenarios

## Milestone 7 — Capstone House

- Full residential brief
- Load assessment
- Circuit planning
- Simulated installation
- Distribution-board assembly
- Verification
- Fault-finding exam
- Final report

## Milestone 8 — Production Readiness

- Performance profiling
- Accessibility
- Localization
- Offline content packaging
- Content validation
- Crash/error reporting
- Release signing
- Play Store packaging

## Definition of Done for v1.0

The learner can complete at least one unseen residential project entirely inside the simulator, explain the electrical principles behind their choices, perform modeled verification tests, and diagnose injected faults without step-by-step assistance.
